# 多电机协作（同步）控制仿真方案

## 1. 研究问题

多电机驱动装备中，各电机参数存在制造离散性（出厂体质差异）
(惯量、摩擦 ±10% 摄动)，负载也会突变。协作控制的目标：让各电机转速保持同步，
不因参数不一致或单机负载突变而"掉队"，同时尽量不影响整体转速跟随。

本仿真回答的问题：主从、交叉耦合、偏差耦合三种经典同步策略，在参数摄动 +
突加负载 + 周期波动负载工况下，谁的同步性能最好？代价是什么？
进一步地：在最强经典策略上叠加扰动观测器(DOB)前馈，能把同步性能再推高多少？

## 2. 被控对象模型

单台电机采用机电简化模型（转速环 + 转矩饱和），第 $i$ 台：
<!-- 后续考虑建模电流环、反电动势等细节 -->
<!--两个 $ 表示"从这里开始是公式"，渲染后是居中独立公式 -->
$$
J_i \frac{d\omega_i}{dt} = T_{e,i} - B_i \omega_i - T_{L,i}
$$ 

| 符号 | 含义 | 取值（1/2/3 号电机） |
|---|---|---|
| $J_i$ | 转动惯量 (kg·m²) |  0.010 / 0.011 / 0.0095 |
| $B_i$ | 粘性摩擦 (N·m·s/rad) | 0.0012 / 0.0011 / 0.0013 |
| $T_{e,i}$ | 电磁转矩，限幅 ±5 N·m | 转速环 PI 输出 |
| $T_{L,i}$ | 负载转矩 | 见工况 |

转速环 PI（含条件抗积分饱和）：

$$
T_{e,i} = \mathrm{sat}_{\pm T_{max}}\left[K_p(\omega_{ref,i} - \omega_i) + K_i \int (\omega_{ref,i} - \omega_i)\,dt\right]
$$

其中 $K_p = 0.8\ \mathrm{N\cdot m/(rad/s)}$，$K_i = 30\ \mathrm{N\cdot m/rad}$。

**推导量纲**（自查用）：$K_p\cdot e$ 的单位是 (N·m/(rad/s))·(rad/s) = N·m ✓；
$K_i$ 的单位是 N·m / rad/s，积分后 ∫e dt 单位 rad，乘起来 N·m ✓。

## 3. 负载工况

| 时段 | 事件 |
|---|---|
| 0 – 0.5 s | 给定转速斜坡 0 → 120 rad/s（软启动） |
| t = 1.2 s | 电机 2 突加 1.8 N·m 恒负载（模拟单机卡滞） |
| t ∈ [1.8, 2.6] s | 电机 4 线性斜坡加载 0 → 1.0 N·m 并保持（渐变负载） |
| t ≥ 2.0 s | 电机 3 施加 0.4·sin(2π·2t) N·m 周期波动负载 |

四种扰动各占一台电机，覆盖"无扰 / 突变 / 渐变 / 周期"完整谱系，
台数扩展时按 `N_MOTOR` 与参数表同步增删即可。

## 4. 三种同步策略

记 $n=4$，$\omega^*$ 为给定转速。所有策略的**区别只在参考转速怎么修正**，
转速环 PI 结构完全相同——这样对比才公平。

### 4.1 主从控制（Master-Slave）

1 号电机为主机跟踪给定，其余跟踪**主机的实际转速**：

$$
\omega_{ref,1} = \omega^*, \qquad \omega_{ref,j} = \omega_1 \ (j = 2,\dots,n)
$$

- 优点：结构最简单，各从机互不干扰。
- 缺点：从机响应滞后主机一个跟踪误差；**主机受扰会传染给所有从机**，
  且从机受扰不会反馈给主机。

### 4.2 交叉耦合控制（Cross-Coupling, CCC）

每台电机计算自己与"其他电机平均转速"之差（同步误差），补偿到自己的参考转速上：

$$
\varepsilon_i = \omega_i - \frac{1}{n-1}\sum_{j \neq i} \omega_j, \qquad
\omega_{ref,i} = \omega^* - \left(K_s \varepsilon_i + K_{si}\int \varepsilon_i\, dt\right)
$$

符号解读：若 $i$ 号比大家快（$\varepsilon_i > 0$），补偿为负，压低它的参考转速；
反之抬高。**单机受扰时全场一起"扶"它，用平均转速的暂时下跌换同步。**

### 4.3 惯量加权偏差耦合控制（Deviation Coupling, DCC）

对**每一对**电机偏差分别补偿，把对方惯量占比作为权重（大惯量电机的偏差更"可信"）：

$$
\omega_{ref,i} = \omega^* - \sum_{j \neq i} w_{ij}\left(K_s(\omega_i - \omega_j) + K_{si}\int (\omega_i - \omega_j)\,dt\right),
\qquad w_{ij} = \frac{J_j}{\sum_{k \neq i} J_k}
$$

与 CCC 的区别：CCC 只对"与平均的差"用一个补偿通道；DCC 对每对偏差各有一个
积分器，且加权后响应更偏向跟随高惯量电机。

### 4.4 偏差耦合 + 扰动观测器前馈（DCC+DOB，本项目创新策略）

前三种策略都是**纯反馈**：误差已经出现了，转速环 PI 才被动调节。
本策略在 DCC 骨架上给每台电机再配一个**扰动观测器**，在线估计"集总扰动"
并**前馈抵消**——不等误差出现就先把扰动补掉，反馈环只负责收拾估计残差。

**① 集总扰动**：用名义参数 $J_n$、$B_n$（取全组均值）改写机械方程

$$
J_n \dot{\omega} = T_e - B_n \omega - d, \qquad
d = T_L + (J - J_n)\dot{\omega} + (B - B_n)\omega
$$

真实负载与 ±10% 参数摄动的影响全被"吸"进 $d$：估计并抵消 $d$，
等价于对**负载扰动和参数失配同时鲁棒**。

**② 观测器构造（关键是避开微分）**：反解 $d = T_e - B_n\omega - J_n\dot{\omega}$
需要微分转速，数值噪声下不可用，故串联一阶低通 $Q(s) = \dfrac{g}{s+g}$
（$g$ 为观测器带宽）：

$$
\hat{d} = Q(s)\left(T_e - B_n\omega - J_n s\omega\right)
$$

利用恒等式 $sQ(s) = g\left(1 - Q(s)\right)$ 消去微分项：

$$
\hat{d} = Q(s)\left(T_e + (gJ_n - B_n)\omega\right) - gJ_n\omega
$$

写成状态方程即代码实现（$x$ 为滤波器状态）：

$$
u = T_e + (gJ_n - B_n)\omega, \qquad
\dot{x} = g(u - x), \qquad
\hat{d} = x - gJ_n\omega
$$

稳态自检（$s \to 0$ 时 $Q \to 1$、$x \to u$）：$\hat{d} = T_e - B_n\omega = d$
（此时 $\dot{\omega} = 0$）✓ 无静差。

**③ 前馈补偿与两条实现纪律**：

$$
T_e^{cmd} = \mathrm{sat}_{\pm T_{max}}\left( T_e^{PI} + \hat{d}_{k-1} \right)
$$

- 观测器输入 $T_e$ 必须取**限幅后实际施加**的转矩，否则饱和期间观测器以为
  电机输出了并没有输出的转矩，估计被系统性估偏（观测器层面的"抗饱和"）；
- 前馈用**上一拍**的 $\hat{d}$：本拍转矩未施加前本拍估计根本算不出来，硬用
  构成代数环；0.1 ms 延迟相对观测器时间常数 $1/g = 10$ ms 可以忽略。

**④ 带宽整定**：取 $g = 100$ rad/s（≈15.9 Hz）。显式欧拉下 $g\Delta t = 0.01 \ll 1$，
稳定余量充足；约为最快扰动（电机 3 正弦负载 2 Hz ≈ 12.6 rad/s）的 8 倍，
该频率下幅值衰减 <1%、相位滞后 ≈7°；与转速环带宽保持 5–10 倍时标分离。

**实测效果**（2 号机突加 1.8 N·m）：$\hat{d}$ 经约 $5/g = 50$ ms 收敛，
稳态值 $1.7895 = 1.8 - 0.0105$，其中 $-0.0105$ 恰为 2 号机摩擦失配项
$(B_2 - B_n)\omega^*$——观测器把负载和参数失配一并估计了出来
（见 `results/dob_observer.png`）。

## 5. 评价指标

| 指标 | 定义 | 说明 |
|---|---|---|
| 同步误差 | $\max_{i,j}\|\omega_i - \omega_j\|$ | 同型电机下等价于 max − min |
| 同步误差 RMS | 升速结束后全程均方根 | 反映整体同步水平 |
| 突加载峰值误差 | t ∈ [1.2, 1.8] s 内最大同步误差 | 抗扰能力 |
| 恢复时间 | 突加后误差回落到 0.5 rad/s 内且连续保持 50 ms | 快速性 |
| 电机 2 最大转速跌落 | 突加后电机 2 最低点与给定之差 | 跟随性代价 |

## 6. 预期现象（用于自查仿真对不对）

1. 升速段：主从的从机滞后主机 → 同步误差不为零；CCC/DCC 耦合通道会主动"拉齐"。
2. 突加载：主从中只有电机 2 自己扛，误差峰值大、恢复慢；CCC/DCC 其他电机转速
   会跟着略降（平均转速牺牲），但**相对**同步误差更小。
3. DCC 与 CCC 接近，加权后对 3 号（最小惯量）电机的波动负载响应略有差别。
4. DCC+DOB：扰动出现的瞬间前馈已就位，突加载峰值误差被压到恢复判定阈值
   （0.5 rad/s）以下，恢复时间归零；周期负载段的同步波动也被显著抹平——
   观测器对正弦扰动同样能有效跟踪。
