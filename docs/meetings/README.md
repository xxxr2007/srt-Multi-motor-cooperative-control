# 组会与评审会模板

> 周会 30 分钟，不做月末长会。每次组会写纪要存本目录（`meetings/纪要_W{周}.md`）。
> 规范依据：`docs/rules.md` §6。

## 一、首次组会议程（建群即开）
1. 组长讲项目目标、4 岗分工、整体节奏（看 `three_month_plan.md` / `weekly_tasks.md`）
2. 过一遍协作规范（`docs/rules.md`）：分支、命名、Deadline、请假、署名
3. 每人认领岗位，填 `weekly_tasks.md`「负责人」栏
4. 定周会时间（周日晚）、请假规则
5. 建共用：Zotero 组库、`data/results/` 目录、周报提交表

## 二、周会议程模板（每周）
1. 上周进度过堂（每人 3 min，对着 `周报_W{周}_{岗位}.md`）
2. 接口对齐（机械→电控 参数交付确认）
3. 本周计划 + 风险
4. 卡点求助（blocked？）
5. 导师/师兄反馈转达（如有）

## 三、评审会模板（迭代期，每轮结束）
1. 本轮机械创新点 + 交付参数
2. 电控更新算法 + 本轮指标
3. 指标 vs 上轮（收敛没？）
4. 下一轮方向（更刚 / 更软 / 调 g / 换策略）
5. 卡点升级（需找导师？）

## 四、纪要模板（每次存 `meetings/纪要_W{周}.md`）
- 日期 / 参会人 / 缺席
- 议题与决议
- 待办（谁 / 什么 / 何时）
- 风险与升级
