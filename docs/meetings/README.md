# 组会与评审会模板（SRT 多电机协同控制）

> 本文件是组会 / 评审会 / 纪要的**唯一模板源**。组规 `docs/rules.md` §5 只写「开几次、何时」，议程细节都在这里，避免两处各写一份。
> 请假 / 缺席规则见 `docs/rules.md` §5，不在此重复。

## 一、首周组会（W1，约 45 min）

1. 组长开场：项目目标、13 周路线图、分组（电控-仿真 / 电控-理论 / 机械-建模 / 机械-选型）
2. 工具链确认：每人 Git 三件套走通、MATLAB / CATIA 装好（未装完的当场排期）
3. 通读 `README.md` + `three_month_plan.md`，统一名词（J / B / Ks / ω_n / 四策略）
4. 定每周固定动作：周日晚 7 点 30 min 周会、每周文献调研 1~2 篇、仿真图命名 + csv+json 留存
5. 分配首周任务，确认周报提交入口 `docs/周报/`

## 二、周会模板（每周日 19:00，30 min，5 项固定）

1. **进度对齐**：机械讲本周交付、电控讲本周曲线，对照 `weekly_tasks.md` 该周状态
2. **机电接口**：本周要不要交接参数（J / B / Ks / ω_n）——有则当场定版本号
3. **卡点升级**：Git 冲突 / 公式 / 软件报错，当场拍板或升级 组长 → 导师
4. **下周微调**：后移 / 砍学习深度，**永远不砍交付物**
5. **周报提醒**：周六 22:00 前交 `docs/周报/W{周}/{姓名}.md`

> **W9 起加一项**：跨组对齐 15 min——机械改 Ks → 电控重跑 → 指标对比闭环（固化成每周动作，不只 W9/W10）。

## 三、评审会模板（迭代期，每轮结束，替代周会）

- 过本轮指标（同步误差 RMS / 调节时间 / 谐振峰），对比上一轮 △
- 拍板本轮收敛与否；不收敛立刻调，不拖到年底
- 填 `docs/Follow-up/weekly_tasks_iteration.md` 该轮记录表 + 指标曲线存 `data/results/`
- 模板见该文件「五、每轮填写模板」

## 四、纪要模板（每次会后台组长写，存 `docs/meetings/纪要_W{周}.md`）

```
## 组会纪要 W{周}（日期）
- 出席：
- 进度：机械 / 电控 各一句话
- 接口交接：（参数 / 版本号）
- 决议：（下周微调、升级事项）
- 待办：（谁 / 啥 / 何时）
```
