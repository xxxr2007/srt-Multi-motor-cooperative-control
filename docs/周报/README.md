# 组员周报提交仓库（docs/周报/）

> 这是组员**每周正式提交周报**的地方。每人每周自己在周次下方创建新的文件，互不干扰，避免大家改同一个文档产生冲突。
> 组长每周六 22:00 后统一审阅，并把各组状态汇总到 `docs/weekly_tasks/weekly_tasks.md`。

## 怎么交（流程）

1. 复制本目录的 `模板_组员周报.md`。
2. 另存为 `W{周}/{你的姓名}.md`，例如 `W1/沈修竹.md`。
   - 周次用 `W1`~`W13`，姓名用本名（全组唯一）。
3. 只看**本周**那一周：对照 `docs/weekly_tasks/weekly_tasks.md` 对应周次的「系统课学习 / 项目交付物 / 验收物」，填自己的完成情况。
4. **学习证明 / 验收物**：实物（笔记、代码、截图、模型）放进仓库对应目录，本文件只写**仓库路径**；截图可直接贴图。
5. 周六 **22:00 前** `commit` + 提 **PR** 给组长（分支规范见 `docs/rules.md`：禁止 force-push、PR 由组长审）。
6. 组长审后合入 `main`，并在 `weekly_tasks.md` 汇总各组状态。

## 命名规范

| 项 | 规则 | 示例 |
|---|---|---|
| 路径 | `docs/周报/W{周}/{姓名}.md` | `docs/周报/W1/沈修竹.md` |
| 周次 | `W1`~`W13` | `W3` |
| 姓名 | 本名，全组唯一 | `张三` |

## 目录结构（预期）

```
docs/周报/
├── README.md            # 本文件（提交指南）
├── 组员周报提交表.md      # 每人每周复制那一周的来填
├── W1/
│   ├── 张三.md        # 示例
├── W2/ … W13/          # 各周文件夹，提交时自己建
```
> 各周文件不需要建即大文件w1,w2等，只需把你的（张三.md文件）放在应该每一周（W1）大文件下面
