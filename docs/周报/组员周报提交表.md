# 组员周报提交表（docs/周报/ 提交模板）

> 这是**组员每周正式提交**的地方。每周六 22:00 前，每人把自己那一周的完成情况填好，提交给组长（沈修竹）。
> 每周的「本周要学 / 要交 / 要证明什么」已按 `docs/weekly_tasks/weekly_tasks.md` 预置好，组员只需在**空白下划线处**填自己的实际情况。
>
> **填写字段说明**
> - **提交人**：本人姓名（必填）
> - **分工编号**：暂不填
> - **本周所学（知识点）**：已按组列出应学内容，学了的打勾、没学的写清原因
> - **学习证明**：证明你真学了的东西——笔记 md / 公式推导 / 代码 / 截图，**必须给仓库路径或附件**
> - **项目交付物**：本周交出的东西（文件 / 模型 / 代码 / 参数表）
> - **验收物**：怎么证明做完了（截图 / 数据 / 曲线 / 跑通记录）
> - **状态**：✅ 完成 / 🔄 进行中 / ⛔ 卡住
> - **备注**：卡点、需协助事项

## 附：提交流程

1. 每周六 22:00 前，组员在本文档对应周次填好**提交人 / 分工编号 / 学习证明 / 状态 / 备注**。
2. 学习证明与验收物：文件放仓库对应目录，本文档只填**仓库路径**；截图可直接贴图。
3. 填完后 commit + push（SourceGit 点 Push 按钮），并在群里 @ 组长。
4. 组长在 `docs/weekly_tasks/weekly_tasks.md` 汇总状态。
