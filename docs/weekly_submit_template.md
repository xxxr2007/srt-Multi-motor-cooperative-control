# 每周任务提交模板（组员填写，直接交组长）

> **用途**：每周五前，按下面的格式填好「本周任务 + 验收物」，**直接提交给组长（沈修竹）**。
> 组长只看交付物、不介入过程——所以**验收物（截图 / 文件 / 推导）必须你自己准备好一并交**，别等组长来问。
> 你的分工与每周安排见 [three_month_plan.md](three_month_plan.md)（电控 D1–D8 / 机械 J1–J6）；知识点见 [study_plan.md](study_plan.md)。

## 提交格式（复制下面的块，填好发组长）

```
提交人（负责人）：
周次：W__（日期：__ ~ __）
分工编号：电控 D__ / 机械 J__（见 three_month_plan.md 分工）
本周任务（对照 three_month_plan.md 该周安排）：
实际完成内容：
验收物（截图 / 文件 / 推导，直接附上或贴仓库路径）：
卡住 / 需协助：
状态：✅ 已完成 / 🔄 进行中 / ⛔ 阻塞
```

## 填写说明

- **负责人**：写你名字；分工编号对应 three_month_plan.md（电控 D1–D8、机械 J1–J6）。
- **验收物**：不接受口头"我会了"。至少交一样可查的东西——曲线截图、模型文件、推导 md，或 `docs/Image description/` 下的图。
- **直接交组长**：发组长（沈修竹）即可，不用等人来催；阻塞项写明原因 + 需要谁帮忙。
- **交叉接口**：机械组 **W4 末**必须交付 `J`、`T_L` 数值给电控组，在这一并写清。
- 周次对照：9/28 起为 W1；9/21–9/27 为准备周。
