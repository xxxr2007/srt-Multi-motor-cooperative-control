# SRT 项目知识库（Knowledge Base）

> 本文件夹集中沉淀本项目在开发 / 协作中遇到的 **Bug、重点知识点、问题 / 卡点、疑惑** 及其解决方法。
> 目的：让组员和本人（以及 AI 助手）遇到新问题时能快速查历史、不重复踩坑；新坑统一往这里加。

## 文件导航

| 文件 | 内容 |
|------|------|
| `bugs.md` | 代码 / 工具 Bug 记录（含复现命令与解决） |
| `keypoints.md` | 重点知识点（公式、准则、架构约定） |
| `blockers.md` | 协作 / 环境卡点（问题 + 解决） |
| `doubts.md` | 当前仍存的疑惑与已找到的解决方法 / 临时结论 |
| `template.md` | 新增条目的模板，照抄即可 |

## 追加约定

1. 新条目放在对应文件 **最前面**（最新的在最上）。
2. 每条带 `[类型]` 标签与日期（如 `[BUG][2026-09-23]`）。
3. **Bug / 卡点类必须写**：现象 → 根因 → 复现命令 → 解决方法。
4. 疑惑类写：疑问 → 已查到的结论 / 临时方案 → 待定项。
5. 不要 push 到 GitHub 除非负责人说“推吧”；本地 commit 也需当轮明确授权。

## 与早期 srt-kb 的关系

本库最初在本地建过独立仓库 `srt-kb`（未上 GitHub），后按负责人要求**迁移至此**，作为 SRT 主仓库的一部分，方便随项目一起共享给组员。
