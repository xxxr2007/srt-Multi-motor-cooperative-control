## [Q][如何快速判断“gcc 失败是代码问题还是环境问题”]
- **疑问**：编译报错时，怎么区分是真代码错还是本机 PATH 假象？
- **已解决**：先跑 hello-world 基准（`printf("hi\n");` 编译运行）。若 hello-world 也 `exit=1` 且 stderr 空 → 100% 是环境（PATH / DLL）问题，不是你代码。再上注入 PATH 重编译确认（见 bugs.md）。
