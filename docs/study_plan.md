# 多电机协同控制 · 两个月系统学习知识点清单（仿真路线）

> 本文件是 `three_month_plan.md` §二·六「按周学习清单」的**纯知识点展开版**：系统学习只安排**前两个月（W1–W8）**，W9–W13 进入联合仿真冲刺，不再系统上课。
> 知识点直接列出，**不绑定具体教材章号**（不同教材版本章号不同，以知识点为准）；需要章号对照时在小组群同步推荐教材版本。
> 主线课程：**自控 + 电机理论 + 电路分析 + 信号/复变/线代 + C（读仿真内核）+ Python（出图）+ MATLAB/Simulink**；STM32/电力电子/模电为加分项（○），不烧板阶段不碰。

## 0. 总原则与图例

- **项目边界**：srt 多电机协同控制 = **算法仿真，不烧板**。STM32 / 电力电子 / 模电等硬件内容在本阶段**降为加分项（○）**，主线是「自控 + 电机理论 + 信号/复变/线代 + C（读仿真内核）+ Python（出图）+ MATLAB/Simulink」。
- **优先级图例**
  - ★ 核心：必学，卡住就进不了项目。
  - ○ 加分：建议学，提升质量，可暂缓不影响交付。
  - △ 暂缓：实物阶段才用，本两个月不碰。
- **验收物**：每周「产出」必须提交到 `weekly_tasks.md`（推导 md / 模型文件 / 曲线截图），不接受口头"我会了"。
- **交叉接口**：机械组 **W4 周末**必须把 `J`（转动惯量）、`T_L`（负载转矩）数值交付电控组，作为仿真被控对象参数。

## 1. W1–W2 打基础

### 电控组
- ★ 自动控制原理：开环/闭环/反馈概念；数学模型（传递函数、框图、梅森公式）
- ★ 电机学：磁路定律（安培环路、法拉第电磁感应）；直流电机工作原理与电磁转矩
- ★ 复变函数与积分变换：拉普拉斯变换（常用变换对、反变换）
- ★ C 语言：指针、结构体、位运算、`volatile`（用于读懂 C 仿真内核）
- ○ 电力电子：MOSFET / IGBT 器件特性（仿真阶段了解即可）

### 机械组
- ★ 理论力学：受力分析、力矩、平面力系平衡
- ★ 材料力学：拉伸压缩、轴力图、强度计算
- ★ 机械原理：自由度计算 `F = 3n − 2P_L − P_H`；齿轮机构 / 渐开线
- ★ 工程制图：三视图、尺寸标注、公差配合
- ★ SolidWorks：草图绘制、实体建模

**本周产出**：电控能推导电机传递函数、用 C 写 PWM 控制程序骨架；机械能画简单零件图、计算简单结构受力。

## 2. W3–W4 建模型

### 电控组
- ★ 自动控制原理：时域分析（一二阶系统响应、劳斯判据、稳态误差）
- ★ 电机学：直流电机机械特性 / 起动调速；异步电机等效电路与转矩表达式
- ○ 电力电子：斩波电路（降压 / 升压）
- ○ STM32：TIM 定时器（PWM 生成）、编码器接口、中断 NVIC（实物阶段）
- ○ 模电：运放比较器、MOS 管驱动电路
- ○ 根轨迹（root locus）直觉：与 Bode 互补看稳定性
- ○ 制图规范：论文插图 / 控制框图标准（draw.io 出图达标线）

### 机械组
- ★ 理论力学：动量矩定理、动能定理
- ★ 材料力学：扭转、扭矩图、圆轴扭转应力与刚度
- ★ 机械原理：轮系传动比（定轴 / 周转 / 复合轮系）
- ★ 机械设计：轴的设计、联轴器选型
- ★ SolidWorks：装配体建模、干涉检查

**本周产出**：电控能搭建电机速度环 PID、读取编码器反馈；机械能计算负载转矩 `T_L` 与转动惯量 `J`、完成电机轴系设计。**（W4 末交付 J / T_L 给电控组）**

## 3. W5–W6 做控制

### 电控组
- ★ 自动控制原理：PID 校正、串联校正、前馈补偿
- ★ 电机学：同步电机、电枢反应、功角特性、转矩平衡方程
- ○ 电力电子：逆变电路（单相/三相电压型）、PWM / SPWM / SVPWM
- ○ STM32：DMA、UART / CAN 通信（实物阶段）
- ★ 信号与系统：低通滤波、均值滤波（编码器数据处理）
- ○ Python 数据处理：numpy / pandas / matplotlib 批量清洗出图（新增技能）
- ○ 离散化 PI 实现 + 抗积分饱和（新增技能，仿真最易翻车点）

### 机械组
- ★ 材料力学：弯曲、内力图、正应力、强度计算
- ★ 机械设计：螺纹联接（预紧防松、螺栓组设计）、滚动轴承选型与寿命计算
- ★ 机械制造技术基础：车铣刨磨加工工艺、定位夹紧
- ★ 互换性与技术测量：公差配合（间隙/过渡/过盈）、表面粗糙度
- ★ 机械振动 / 两质量系统动力学：扭转振动、谐振机理（**新增核心技能**，理解「柔为何放大同步误差」，与电控 `ω_n` 同一套语言）
- ○ 有限元具体操作：CATIA 创成式 / ANSYS 看强度结果（新增技能，验证选型）
- ○ 传动误差 / 背隙（backlash）：机械侧同步误差头号来源

**本周产出**：电控能实现多电机同步控制逻辑、用滤波处理编码器数据；机械能完成轴承/螺栓选型、输出可加工零件图。

## 4. W7–W8 联调优化

### 电控组
- ★ 自动控制原理：串级 PID（电流环 + 速度环 + 位置环）
- ★ 电机与拖动：运动方程式、负载转矩特性
- ○ 电力电子：续流二极管、死区时间、驱动保护电路
- ○ STM32：FreeRTOS 多任务（任务创建 / 信号量 / 消息队列，实物阶段）
- ★ 线性代数：矩阵运算、特征值（为现代控制理论铺垫）
- ○ 系统辨识 / 参数辨识：从仿真数据反推 J / B / Ks（新增技能，迭代期电控倒逼机械重测）
- ○ 仿真指标定义：同步误差 RMS、调节时间、谐振峰怎么算 / 判好坏（新增技能）

### 机械组
- ★ 材料力学：应力状态与强度理论
- ★ 机械设计：齿轮传动失效形式与强度校核、疲劳强度 / 接触强度
- ★ 工程材料：钢材 / 铝合金特性、热处理、选材逻辑
- ○ 电工电子技术：电机 / 传感器基本电气原理（方便与电控组对接）
- ○ 有限元具体操作：CATIA 创成式 / ANSYS 看强度结果（新增技能，验证选型合理）
- ○ 文献精读 + 提炼创新点：机电协同迭代设计叙事（新增技能，为申报书铺垫）
- ○ 摩擦模型（Stribeck / LuGre）：理解 `B` 在模型里的物理意义
- ○ 论文写作结构：摘要 / 引言 / 方法 / 结果 / 讨论 怎么写

**本周产出**：电控完成三闭环控制调试、实现多电机协调运动；机械完成整体结构强度校核、输出最终加工图纸。

## 5. 关键节点检查

- **W2 末**：电控能点亮电机（仿真中跑通单机转速环）、机械能出简单零件图。
- **W4 末**：电控能闭环调速、机械能算出 `T_L` 与 `J` 并交付电控组。
- **W6 末**：电控能多电机同步控制、机械能出装配图。
- **W8 末**：整机联调，多电机协调运动跑通。
