# 多电机协同控制 · 机电协同迭代创新周表（W13 之后约一年）

> **本文件覆盖 W13 之后约一年（2027 全年）的迭代研发期**，是 `three_month_plan.md`（仅 W1–W13 学习期）与 `annual_innovation_plan.md`（年度总览）的**逐轮执行展开版**。
> 主线 = **机电协同迭代创新**：机械创新 → 交付 → 电控更新算法 → 反馈 → 再创新，良性循环。
> 组长 / 各岗位直接在此填每一轮的进展、指标与验收。
>
> **节奏**
> - 每 **2~3 周完成一轮迭代**，全年约 **13~20 轮**。
> - 周会改「**迭代评审会**」：每轮结束过一遍指标，卡住立刻调，不拖到最后。
> - 指标逐轮收敛即定稿一轮，进入下一轮更优解。

## 一、岗位与交叉接口（沿用 weekly_tasks.md）

| 岗位 | 组 | 迭代期干啥 |
|---|---|---|
| **电控-仿真（A）** | 电控 | 接机械参数跑仿真、复现策略、系统辨识反推、扫刚度、出指标曲线 |
| **电控-理论（B）** | 电控 | 算法更新（调 g / 加陷波器 / 换策略 / DOB）、整理指标口径、写创新点 |
| **机械-建模（C）** | 机械 | 改结构 / 重测惯量 J、出质量属性、提供建模侧参数 |
| **机械-选型（D）** | 机械 | 换联轴器 / 调 Ks·Ds、查手册、算 ω_n、交付参数 v(n) |

**交叉接口（每轮都走）**：`J` / `B` / `Ks` / `Ds` / `ω_n` —— 由产出方主责、接收方配合。

---

## 二、每轮闭环（固定 4 步）

1. **机械创新**：改 Ks/Ds · 换联轴器 · 调结构 · 重测惯量 J
2. **交付参数 → 电控**：新参数 / 结构交给电控组接手
3. **电控更新算法**：调 g · 加陷波器 · 换策略 · 重新仿真出指标
4. **反馈刚度需求 → 机械**：当前刚度够不够？要不要更刚 / 更软

---

## 三、指标口径（全程统一，轮轮可比）

| 指标 | 含义 | 怎么算 / 判好坏 |
|---|---|---|
| 同步误差 RMS | 多电机转速同步精度 | 各电机转速与参考的均方根误差，越小越好 |
| 调节时间 | 进入稳态的快慢 | 阶跃响应落到 ±2% 带宽所需时间，越短越好 |
| 谐振峰 | 柔性传动链谐振强度 | Bode 图在 `ω_n` 附近的峰值（dB），越低越好（陷波器/更刚可压） |

> 口径在 W9 已统一（见 `weekly_tasks.md` W9 仿真指标定义），迭代期直接复用，不另立标准。

## 六、创新点叙事（写进申报书 / 结题报告）

> **创新点二：机电协同迭代设计方法**——机械组与电控组不是「一次优化」，而是「机械创新 → 交付 → 电控更新 → 反馈」逐轮倒逼、指标逐轮收敛的良性循环。每轮都走同一套闭环、用同一套指标口径（同步误差 RMS / 调节时间 / 谐振峰），天然形成可复现的迭代曲线（同步误差-刚度扫描曲线、逐轮收敛曲线），是项目最硬的创新叙事。
