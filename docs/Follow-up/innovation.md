# 创新点专述：机电协同迭代设计方法

> 可直接抄进申报书「创新点」与论文「引言/讨论」。核心：不是一次性优化，而是机械-电控互相倒逼、指标逐轮收敛。
> 配套：迭代机制见 `weekly_tasks_iteration.md`；指标口径见 `acceptance_metrics.md`；数据留档见 `rules.md` §4。

## 一、背景与痛点
- 多电机同步系统里，机械侧（柔联轴器、背隙、摩擦）和电控侧（控制策略、刚度匹配）强耦合
- 传统做法：机械定型后电控硬调，或电控假设理想机械——两边脱节，同步误差下不来
- 痛点：机械不知道电控要什么刚度，电控不知道机械能给什么刚度

## 二、我们的做法：机电协同迭代
- 闭环：机械创新（改 Ks / 换联轴器 / 重测 J）→ 交付参数 → 电控更新算法（调 g / 加陷波器 / 换策略）→ 仿真出指标 → 反馈刚度需求 → 机械再创新
- 每轮用统一指标（同步误差 RMS / 谐振峰 / 调节时间）判定收敛
- 系统辨识介入：电控从仿真数据反推 J/B/Ks，校验机械测量，倒逼机械重测——形成数据闭环

## 三、预期贡献（创新点）
1. 提出「机械-电控协同迭代」的设计流程，替代单次定型
2. 建立刚度-算法协同寻优方法（扫 `Ks×g`，找优选组合）
3. 用系统辨识打通「机械测量-电控仿真」的数据闭环

## 四、可落成产出
- 论文方向：多电机同步的机电协同迭代设计 / 刚度-控制协同优化
- 专利方向：一种基于迭代收敛的传动刚度匹配方法（视收敛结果定）
- 申报书创新点二：机电协同迭代设计方法
