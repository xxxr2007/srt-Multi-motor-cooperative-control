> 本文档是项目全部创新点的**唯一汇总**，分三层：① 算法层（创新点一）② 对象与准则层（创新点二）③ 方法论层（创新点三）。
> 申报书「创新点」、论文「引言/讨论」可直接抄。配套：迭代机制见 `docs/Follow-up/weekly_tasks_iteration.md`；指标口径见 `docs/acceptance_metrics.md`；数据留档见 `docs/rules.md` §4。

## 创新点一：偏差耦合 + 扰动观测器（DOB）前馈复合策略

- **做法**：在偏差耦合骨架上加入扰动观测器前馈，约 50 ms 内估计并前馈抵消负载扰动与 ±10% 参数摄动。
- **证据**（四电机，含参数摄动 + 单机突加负载）：
  - 同步误差 RMS：DCC 0.098 → DCC+DOB **0.041**（再降 58%）
  - 突加载峰值：0.873 → **0.494**（再降 43%）
  - 恢复时间：归零（峰值已低于 0.5 rad/s 判定阈值）
- **贡献**：把耦合类策略的同步精度再推一档，且对模型不精确鲁棒。

## 创新点二：弹性传动链双惯量对象 + 带宽-刚度匹配量化准则

- **做法**：仿真内核支持「刚性直连」升级为 `J₁ — (Ks, Ds) — J₂` 双惯量模型（`plant_step2`），机械组填 `coupling.Ks` 即自动启用；未交付退回刚性基线，**验收基线不受影响**。
- **量化准则（核心创新）**：机械刚度决定控制带宽需求，控制带宽反过来约束联轴器选型——
  `ω_n = √(Ks·(1/J₁+1/J₂))`，要求 DOB / 陷波器带宽覆盖 ω_n 的 2~5 倍。
- **反直觉结论（实证，硬证据，g=100 固定）**：固定观测器带宽时，三个弹性档**全部劣于刚性基线 0.041**——既非「越软越好」，也非「越刚越好」，单看 `Ks` 没有优选区间：
  - 中等弹性 `Ks=200`：`ω_n=199`，`g/ω_n=0.50`（远低于 2 倍覆盖），DOB 压不住谐振，RMS **0.670**（全面恶化）；
  - 软弹性 `Ks=12`：`ω_n=49`，`g/ω_n=2.05`，但谐振落进转速环带宽内被环路激励，RMS **2.710**；
  - 近刚性 `Ks=2000`：`ω_n=629`，`g/ω_n=0.16`，谐振高过环路带宽，峰值/跌落改善但 RMS 受欠阻尼振荡拖累 **0.624**。
  两头差、中间也不行，说明**「优选」是 (Ks, g) 的协同组合，不是单一 Ks**：选好刚度后必须把观测器/陷波带宽提到覆盖 `ω_n` 的 2~5 倍（或加 notch @ ω_n），才能把弹性 RMS 压回基线。这正是「带宽-刚度匹配」准则的工程价值（数据见 `README.md` 创新点二 三档样例表）。
- **证据**：`README.md`「创新点二」三档样例表（Ks=200/12/2000）+ `fig_W10_刚度扫描_同步误差RMS.png`。
- **专利方向**：一种基于迭代收敛的传动刚度匹配方法（视收敛结果定）。

## 创新点三：机电协同迭代设计方法论

- **背景痛点**：机械（柔联轴器 / 背隙 / 摩擦）与电控（控制策略 / 刚度匹配）强耦合，传统「先定型后硬调」脱节，同步误差下不来。
- **做法**：闭环 机械创新 → 交付参数 → 电控更新算法 → 仿真出指标 → 反馈刚度需求 → 机械再创新，每轮统一指标判定收敛。
- **三个子贡献**：
  1. 「机械-电控协同迭代」设计流程，替代单次定型
  2. 刚度-算法协同寻优方法（扫 `Ks×g` 找优选组合）
  3. 系统辨识打通「机械测量-电控仿真」数据闭环（电控反推 J/B/Ks 校验机械测量，倒逼重测）
- **可复现性创新**：每轮参数冻结（`params_freeze_v1.0.json`）+ 指标曲线 csv+json 留档，天然形成**逐轮收敛曲线**——这是最硬的证据链。
- **论文方向**：机电协同迭代设计 / 刚度-控制协同优化。

## 六、现阶段最新研究概括（2024–2026，文献支撑，非杜撰）

### 电控（多电机同步 / 先进控制）
- **架构演进**：集中式 → 分布式 → **混合智能**（Gao 2026 综述明确三阶段）。本项目「偏差耦合」属分布式，"DCC+DOB"已在混合智能边缘。
- **算法融合是主流**：① SMC + ADRC（Zhang 2025：响应 +18.9%、同步精度 +46.7%）；② 全局快速终端滑模 GFTSMC + DOB 估摩擦转矩（Wu 2025）；③ MPC + 神经网络（GRU 近似模型 / NARX 加速求解）做"轻量+强泛化"。
- **观测器升级**：从 ESO → **PLL-ESO**（更高带宽、更大相位裕度，宽 ω_n 范围有效）——这是本项目 DOB 最自然的下一步。
- **未来方向（综述共识）**：异构电机集成、能效-精度协同优化、**数字孪生实时增强**、边缘计算分布式架构、AI 与传统控制更深融合。

### 机械（双惯量 / 柔性传动 / 谐振）
- **谐振抑制**：PLL-ESO 已成为比陷波滤波器/常规 ESO 更优的机械谐振观测方案（吴春 2024，实验验证更快更准）。
- **谐振机理**：柔轴 + 多惯量显著放大转速/负载谐振敏感性，双惯量→三惯量建模是趋势（Zhang 2024 IET）。
- **自适应整定**：柔性联轴器等效柔性关节 + BP-PID 自适应，应对时变摩擦/刚度/背隙（Xu 2024）。
- **与电控的接口**：机械侧的 Ks / J / B 正是电控侧 ω_n 与带宽匹配的输入——**机电磁协同参数匹配**是跨域创新高地。

> 一句话概括创新点在哪里：**不在单点算法，而在"机械刚度-控制带宽"的协同匹配 + 逐轮迭代收敛的证据链**。本项目三层创新正好踩中这条主线。
