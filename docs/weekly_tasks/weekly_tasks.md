## 二、逐周任务

每周均执行上述 9 h 分配。下列“学习”各组 3 h，“基础”1 h，“实践”2.5 h，验收包含在实践与周会内，不重复加时。

### W3｜2026-10-12–10-18：结构与查漏补缺

- **电控学习**：① 电枢、磁极、换向器、电刷；主极轴线与几何中性线。② `Te=Kt*i`、`E=Ke*ω` 的含义及电压输入/转矩输入模型区别。材料 E1、E2。
- **机械学习**：① 识别现有装配的转动件、固定件、轴承。② 装配树、隐藏/压缩、固定/浮动、外部引用；修复已有模型，不重做整机。材料 M1。
- **基础**：rpm 与 rad/s 换算，转矩、功率、惯量的单位。
- **实践/验收**：电控交能量和信号框图；机械交标注构件及转轴的图、可打开的模型。各解释 3 分钟，列出未掌握内容。已会的操作直接用练习证明。

### W4｜2026-10-19–10-25：转动方程与惯量

- **电控学习**：① 力矩平衡 `J*dω/dt=Te-B*ω-TL`。② 状态、初值、负载与粘性阻尼。材料 E2、B1。
- **机械学习**：① 力矩、角加速度、转动动能。② 圆盘 `J=mr²/2` 与平行轴定理，区别质量惯量和截面惯性矩。材料 M2。
- **基础**：导数是变化率、积分是累积。
- **实践/验收**：教学例 `J=.02 kg·m²,B=.1 N·m·s/rad,Te=1 N·m,TL=0,ω0=0`，算初始加速度 50 rad/s²、稳态 10 rad/s；机械建圆盘并提交尺寸、密度、轴和手算 J。

### W5｜2026-10-26–11-01：一阶响应与质量属性

- **电控学习**：① 一阶微分方程指数解。② MATLAB 数组、函数句柄、ode45、图例和单位。材料 B1、T1。
- **机械学习**：① CAD 质量属性坐标系和惯量张量。② 指定实际旋转轴、材料密度，检查装配是否重复计数。材料 M1、M2。
- **基础**：指数、时间常数 `τ=J/B`、单位平方换算。
- **实践/验收**：电控将数值解与 `ω=(Te/B)*(1-exp(-B*t/J))` 叠图，W4 例题 `ω(.2)≈6.321 rad/s`；机械圆盘 CAD/手算差异超过 1% 先查轴、单位和几何。`kg·mm²→kg·m²` 乘 10^-6，`g·mm²→kg·m²` 乘 10^-9。

### W6｜2026-11-02–11-08：积分误差与参数来源

- **电控学习**：① 显式 Euler、步长、截断误差。② RK4 四个斜率的概念；ode45 不等于固定步长 RK4。材料 B1、T1。
- **机械学习**：① 简化转子—轴—负载盘及惯量求和。② B 的手册、实验、假设来源；CAD 质量属性不能直接测 B/Ds。材料 M1、M2。
- **基础**：绝对/相对误差和同一时刻比较。
- **实践/验收**：电控比较 h、h/2、h/4；机械交 J/B 来源表，缺失项标为假设范围。Euler 的 `0<h<2J/B` 仅适用于该一阶稳定线性例题。

### W7｜2026-11-09–11-15：拉氏变换与参数交接

- **电控学习**：① 常数、指数、正弦变换对及简单反变换。② `L{ω'}=sΩ-ω(0)`，零初值推导 `G(s)=1/(Js+B)`。材料 E3。
- **机械学习**：① 定义传动比 `i=ωm/ωL`。② 负载惯量折到电机侧 `JL/i²`，先做 i=1 再做简单减速例。材料 M2、M3。
- **基础**：分式与方程移项；机械只需理解微分转代数。
- **实践/验收**：共同交参数 v1，明确作用轴和是否已折算；不能重复折算。当前 sync 脚本把单值 J1/B 映射成四台同型参数，不是四组独立测量数据。

### W8｜2026-11-16–11-22：负反馈与比例控制

- **电控学习**：① 给定、反馈、误差、对象框图。② `Te=Kp*(ωref-ω)` 的稳态误差、速度和限幅。材料 E2、E3。
- **机械学习**：① 负载扰动的物理解释。② 简化件必要尺寸、轴线、材料与工程图；暂不做全套制造图。材料 M2、M3。
- **基础**：稳态令导数为零。
- **实践/验收**：电控比较两个 Kp，同时交转速与转矩；机械交有来源或明确假设的负载说明。若有中期汇报，展示这些实际成果即可。

### W9｜2026-11-23–11-29：单机 PI

- **电控学习**：① 积分消除恒定工况稳态误差的机制。② `I[k+1]=I[k]+e[k]*dt` 与 `Te=Kp*e+Ki*I`，先在无饱和小信号范围学习。材料 E3、E4。
- **机械学习**：① J、B、恒负载对启动的不同影响。② 构造轻载/重载场景并标明依据。材料 M2。
- **基础**：矩形积分和 Kp/Ki 量纲。
- **实践/验收**：同条件 P/PI 对比，机械互查参数；能解释超调与积分状态，不要求第一次调到最优。

### W10｜2026-11-30–12-06：饱和与单机过关

- **电控学习**：① 转矩限幅和积分饱和。② 条件积分/钳位，比较抗饱和开关。材料 E4。
- **机械学习**：① 名义/峰值/持续允许转矩。② 核对负载和执行器边界；无实物型号就标教学假设。材料 M3。
- **基础**：超调、稳态误差、误差带与调节时间。
- **实践/验收 G1**：启动及一次阶跃负载；独立复现 PI，解释限幅期间积分变化。模型、参数、程序和一页解释齐全才进多机，否则重复本周。

### W11｜2026-12-07–12-13：最小 C 阅读路径

- **电控学习**：① C 数组、循环、函数、结构体及必要指针。② main→状态更新→PI→输出的调用链，不读完所有算法。材料 T2、R1。
- **机械学习**：① 参数表与生成文件关系。② CAD 源文件、引用和 STEP 的重开检查。材料 M1、R1。
- **基础**：Git diff、源文件与生成物。
- **实践/验收**：电控在小练习里更新一个状态并讲清三个函数；机械交可在他人机器重开的模型包。不要求逐行抄注释。

### W12｜2026-12-14–12-20：跑通项目与出图

- **电控学习**：① 参数生成、编译、运行。② Python 读 CSV、选列、画图、保存，不另学全套 pandas/Jupyter。材料 T3、R1。
- **机械学习**：① 核对 sync 前后 J/B/Ks/Ds。② 在副本中验证输入和输出映射，保护有效基线。材料 R1。
- **基础**：记录版本、参数快照、命令和输出路径。
- **实践/验收**：共同复现当前仓库，确认刚性还是双惯量；不要求此时理解四种算法，不拿 README 旧数值当保证答案。考试冲突改 2 h 回顾并顺延。

### W13｜2026-12-21–12-27：两机独立 PI 与指标

- **电控学习**：① 两机相同给定独立控制。② 跟踪/同步误差及代码中的指标窗口。材料 E3、R1。
- **机械学习**：① 参数差异的来源。② 仅改变一台 J 或负载，设计可解释场景。材料 M2。
- **基础**：均值、极差、RMS；手算两机 9/11 rad/s、给定 10 的例子。
- **实践/验收**：无扰/单机加载对比；当前 `sync_error()` 是 `max(ωi)-min(ωi)`，该量的时间 RMS 不等于相对给定的跟踪 RMS。

### W14｜2026-12-28–2027-01-03：主从控制

- **电控学习**：① 主从信号方向。② 分别对主/从机加载的影响。材料 R1。
- **机械学习**：① 负载变化对应哪个部件。② 复核惯量折算与模型边界。材料 M3、R1。
- **基础**：信号流与力矩流的区别。
- **实践/验收**：同参数/限幅/初值对比独立 PI 与主从；解释不对称性及平均转速下降。考试冲突整体顺延。

### W15｜2027-01-04–01-10：交叉耦合

- **电控学习**：① 两机速度差反馈的符号。② 从零增加耦合增益观察相互作用。材料 E3、R1。
- **机械学习**：① 单台负载对其他电机的间接影响。② 统一无扰/单机阶跃场景。材料 R1。
- **基础**：向量与矩阵乘法，仅补组织多机变量所需部分。
- **实践/验收**：交叉耦合与主从同条件比较同步、跟踪和控制量，保留失败振荡图。

### W16｜2027-01-11–01-17：偏差耦合与四机

- **电控学习**：① 平均速度和惯量权重。② 仓库 CCC/DCC 的实际拓扑、权重和公式。材料 R1。
- **机械学习**：① 同型假设与独立参数来源。② 权重惯量所在的轴与测量依据。材料 M2、R1。
- **基础**：加权平均和归一化。
- **实践/验收 G2**：两机扩到四机，同参数比较三个经典策略，解释同步与跟踪取舍；不预设谁一定最好。

### W17｜2027-01-18–01-24：圆轴扭转与双惯量

- **电控学习**：① `ωm,ωL,θm-θL` 三个状态。② `Ts=Ks*(θm-θL)+Ds*(ωm-ωL)` 与两侧平衡。材料 B2、R1。
- **机械学习**：① 均匀轴 `Ks=G*Jp/L` 的适用条件。② 截面极惯性矩 Jp（m⁴）与转动惯量 J（kg·m²）的区别。材料 M3。
- **基础**：储能/耗能与力矩正负号。
- **实践/验收**：共同交方程及机构简图，先 i=1、同一作用轴；联轴器两侧作用反作用相反。不把均匀轴公式直接当复杂联轴器实测值。

### W18｜2027-01-25–01-31：振动与刚度来源

- **实践/验收 G3**：两档有来源或标为假设的 Ks，频率计算与仿真数量级核对、步长对照；假期可顺延。

## 三、接口与执行规则

- 机械负责结构、J 核对、B/Ks/Ds 来源与不确定性；电控负责方程实现、控制、指标与复现。共同确认单位、作用轴和正负号。
- CAD 源文件放 `mechanical/cad/`，遵守 LFS；说明放 `mechanical/docs/`。交接 STEP + 参数说明，不再混用 `mechanical/catia/`。
- 机械唯一手填入口 `data/shared/mech_deliverables.csv`；控制入口 `data/electrical/ctrl_params.json`。来源/页码/日期/轴/假设范围写随附说明。练习用副本，不覆盖有效基线。
- 当前 `tools/sync_mech_to_elec.py` 会写机械 JSON 并调用 merge。机械改动后 sync→检查差异→编译→运行→画图→验收；只改控制参数则从 `electrical/c/merge_params.py` 开始。生成 JSON/头文件不另行手改。
- Ks>0 会启用当前双惯量内核，必须明确记录对象模式；不同对象不能冒充同条件比较。
- 同步 RMS 按当前代码的转速极差计算；另报跟踪误差。注明电机侧/负载侧、时间窗、恢复阈值。“恢复 0 s”可能仅因峰值未超过阈值。
- 每周成果仍放现有 `docs/周报/`，记录源文件、参数版本、数据与结论；不要只保留 gitignore 目录内的图。
- 旧 `tools/check_coverage.py` 是全课程关键词覆盖检查，不能作为本版能力验收，更不能为了通过它重新加入删减课程。以 G1–G4 的证据为准。
