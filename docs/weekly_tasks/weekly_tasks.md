# 多电机协同控制 · 每周任务执行表（W0–W13，逐周拆解 + 工时估算）

> 本文件是 `three_month_plan.md` 的**逐周执行展开版**：把每份周计划里的「学什么 / 交什么 / 怎么验收 / 机电怎么交接 / 状态 / 备注」全部拆成可填的字段，并给出**每项任务的预计工时**。
> 组长可直接在此改负责人、微调交付物与工时；组员照「系统课学习」「项目交付物」「验收物」执行。
>
> **工时口径说明**
> - 单位为**课外投入工时**（不含上课时间），按「零基础 ⇒ 能做完」估算。
> - 每条任务后的 `约 X h` 是**单人**投入；每周给出「电控 X h/人、机械 Y h/人」小计。
> - 全组按 **6 人（电控 3 人 + 机械 3 人）** 计算总工时。
> - 估算留约 15% 缓冲，实际按个人基础浮动 ±30%。
>
> 字段说明：
> - **负责人**：留空，由组长分配后填写。
> - **系统课学习**：★ 核心（必学）/ ○ 加分（可缓）；知识点已细化到每周。
> - **项目交付物**：本周必须产出的东西（表 / 模型 / 曲线 / 报告）。
> - **验收物**：交什么、怎么证明做完了（文件 / 截图 / 数据）。
> - **交叉接口动作**：机械组与电控组之间本周要交接的东西（无则写「无」）。
> - **状态**：⏳ 未开始（计划中）/ 🔄 进行中 / ✅ 完成 / ⛔ 阻塞。
> - **备注**：关键提醒、风险点、容易踩的坑。
