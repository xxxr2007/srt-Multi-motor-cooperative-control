# 多电机协同控制 · 每周任务执行表（W0–W13，逐周拆解 + 所需时间）

> 本文件是 `three_month_plan.md` 的**逐周执行展开版**：把每份周计划里的「学什么 / 交什么 / 怎么验收 / 机电怎么交接 / 状态 / 备注」全部拆成可填的字段，并给出**每项任务所需的时间**。
> 组长可直接在此改负责人、微调任务与时间。
>
> **时间口径说明**
> - 每条任务后面直接标注该项**所需时间**（`[X h]`）。
> - 每周头部给出**本周所需时间合计** = 该周所有任务时间之和。
> - 全文末尾给出**全周期所需总时间** = 各周合计之和。
> - 估算按「零基础 ⇒ 能做完」，留约 15% 缓冲，实际浮动 ±30%。
>
> 字段说明：
> - **负责人**：留空，由组长分配后填写。
> - **系统课学习**：★ 核心（必学）/ ○ 加分（可缓）；知识点已细化到每周。
> - **项目交付物**：本周必须产出的东西（表 / 模型 / 曲线 / 报告）。
> - **验收物**：交什么、怎么证明做完了（文件 / 截图 / 数据）。
> - **交叉接口动作**：机械组与电控组之间本周要交接的东西（无则写「无」）。
> - **状态**：⏳ 未开始（计划中）/ 🔄 进行中 / ✅ 完成 / ⛔ 阻塞。
> - **备注**：关键提醒、风险点、容易踩的坑。
