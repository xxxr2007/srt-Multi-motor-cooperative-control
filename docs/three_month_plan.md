# SRT 多电机协同控制 · 三个月零基础学习与任务计划

> **适用对象**：机械组 2 人 + 电控组 2 人，**默认零基础**（软件没装过、课程没学过、工具没用过）。
> **周期**：2026-09-21 至 2026-12-20，共 13 周。
> **用法**：每周任务是"底线"（做完打 ✅），学习内容是"自习清单"。组长每周日晚微调下一周；
> 进度落后就把任务后移、砍学习深度，**永远不要砍交付物**（表、参数、模型、报告）。
> 本文档是初始版本，组长可直接编辑调整；每周实际安排请同步记录在 `weekly_tasks.md`。

## 零、第 0 周准备清单（9/21–9/22，所有人，一次性）

- [✅] 注册 GitHub 账号，把用户名发给组长，拉进仓库协作者
- [✅] 安装工具（装好就行，不用会用）：
  - 全员：Git+ SourceGit（图形界面，不用背命令），work buddy
  - 机械组：CATIA
  - 电控组：MATLAB 2024b
- [✅] 全员用 SourceGit **克隆（Clone）** 组长仓库到自己电脑
- [✅] 学会三个动作（会用就行）：
  1. ** Pull**（拉取别人的最新进度）——每天开工第一件事
  2. **Commit + Push**（保存并上传自己的修改）——每天收工最后一件事
  3. **改东西前先 Pull**——避免冲突弹窗
- [✅] 全员读一遍仓库 `README.md`（看不懂没关系，混个眼熟）

**验收标准**：每人能 clone 仓库、pull、commit 并 push 一个改动（比如在 `weekly_tasks.md` 写一句"我进组了"）。

## 二、逐周计划

### W1（9/21–9/27）：全组热身
- **公共学习**：① 会用 Git 三件套（见第 0 周清单）；② 看两个 B 站入门视频（各 1 小时内）：搜"Git 入门 30 分钟"、"多电机同步控制 是什么"。
- **机械组**：查 3 篇文献（关键词：多电机同步 / 传动系统动力学 / 弹性联轴器），各写 5 行摘要交 `mechanical/docs/`。
- **电控组**：安装 MATLAB；学 MATLAB 最基础操作（命令行算数、定义变量、画 `plot(sin(0:0.1:10))`）；B 站搜"MATLAB 一小时入门"。
- **组长**：搭好 `weekly_tasks.md` 更新节奏；确认全员 Git 走通。

### W2（9/28–10/4）：数学 + 建模各补各的地基
- **电控组学习（本周重点，零基础版）**：
  - 什么是"微分"：转速 ω 是角度 θ 的变化率（先建立直觉，不必会算）
  - **拉普拉斯变换**只学一件事：微分 ↦ 乘 s（把它当"翻译规则"背下来即可）
  - 教材：《自动控制原理》前两章；视频推荐西北工业大学卢京潮老师网课（前几节）
- **机械组学习**：CATIA 基础操作——草图、拉伸、旋转成体；B 站搜"CATIA 零件设计入门"跟做 2 个小零件。
- **任务**：电控组用 MATLAB 画出 `J*dw/dt = Te - B*w` 的仿真曲线（抄 `electrical/matlab/multi_motor_sync_matlab.m` 前半段也行，跑通为准）。

### W3（10/5–10/11）：核心公式 + 建模开练
- **电控组学习**：**唯一必须吃透的公式** `J·dω/dt = Te − B·ω − T_L`（仓库 `docs/control_scheme.md` 第 2 章，逐行读，读不懂问组长）。理解 PI 控制："误差×Kp + 误差积分×Ki"。
- **机械组任务**：CATIA 建**简化传动链**：电机转子（圆柱近似）+ 联轴器 + 负载盘。不用精确，能出质量属性就行。
- **机械组学习**：CATIA「测量惯量 Measure Inertia」怎么用；**先切 MKS 单位**再测（工具→选项→参数与测量→单位）。

### W4（10/12–10/18）：🚩 交付一 —— 参数 v1
- **机械组任务（本周头等大事）**：把 4 台电机的 `J`（绕电机轴）填进 `mechanical/params/motor_params.xlsx` 的 B 列；`B`（摩擦）查轴承手册或用经验值 1e-3 量级顶上。
- **电控组任务**：组长带着跑通全链路一次：`xlsx → json → merge → 编译 → 仿真 → 验收判定`（命令在 `docs/collaboration.md`），体会"参数怎么流进仿真"。
- **电控组学习**：Simulink 入门（B 站"Simulink 入门 1 小时"）：会拖增益块、积分器、求和块、示波器，会设置仿真时间。
- **里程碑**：机械参数 v1 交接完成（xlsx 交出 + 转换入库）。

### W5（10/19–10/25）：Simulink 搭第一台"电机"
- **电控组任务**：Simulink 搭**单电机 + PI 转速环**：照 `control_scheme.md` 的公式连线（增益=1/J、积分器、反馈用转速）。跑出启动曲线就算成功。
- **机械组学习**：联轴器是什么、三大类（刚性/弹性柱销/膜片）各自特点；扭转刚度 `Ks` 的含义（扭 1 弧度需要多大力矩，单位 N·m/rad）。
- **机械组任务**：查 2~3 个联轴器型号的手册，抄下 `Ks` 候选值，填交接单第 3 节。
- **公共**：周会 30 分钟——机械讲建模、电控讲 Simulink 进展。

### W6（10/26–11/1）：两线合拢
- **电控组任务**：Simulink 搭**四电机版**（复制 4 份单电机 + 负载工况块），参数全部用变量名（先跑 `electrical/matlab/params_setup.m` 载入工作区）。复现"主从"策略曲线。
- **机械组任务**：算各联轴器方案的谐振频率 `ω_n = √(Ks·(1/J₁+1/J₂))`，**这个数必须交**（它决定电控能不能压住谐振）。
- **里程碑**：电控拿到 ω_n，开始判断联轴器方案可行性。

### W7（11/2–11/8）：四策略复现（电控大周）
- **电控组任务**：依次复现 CCC、DCC 策略的 Simulink 曲线，与 `results/` 里的 C 版结果对比（趋势一致即可，数值允许小差异）。
- **机械组任务**：写**机构简图 + 参数来源说明**（哪来的、为什么选它），充实 `mechanical/docs/plant_model.md`。
- **机械组学习**：什么是谐振、为什么柔会把同步误差放大（组长讲 30 分钟或看 `control_scheme.md` §4.4）。

### W8（11/9–11/15）：中期检查周
- **全组任务**：中期材料——每组整理自己两页 PPT（机械：建模+选型；电控：策略+曲线）。
- **电控组任务**：对照中期反馈修模型；尝试复现 DCC+DOB（DOB 部分允许只调用、不推导）。
- **里程碑**：中期检查通过；Simulink 与 C 内核结果定性一致。

### W9（11/16–11/22）：🚩 联合仿真首轮
- **机械组任务**：把选定的 `Ks/Ds` 正式填进 `mech_params.json`（走 xlsx→转换脚本），交付 v2。
- **电控组任务**：跑**弹性传动链双惯量模型**（Ks>0 自动启用），观察同步误差变化，记录三档 Ks 对比数据。
- **里程碑**：机械改动 → 电控重跑 → 指标对比，**协同闭环转完第一圈**。

### W10（11/23–11/29）：机电协同分析（创新点周）
- **电控组任务**：带宽-刚度匹配分析——扫 `Ks × g`，出"同步误差 vs 传动刚度"曲线（这张图是报告核心图之一）。
- **机械组任务**：根据仿真结果反推——当前联轴器够不够？要不要换更刚/更软的？给出工程理由（这就是"机电协同设计"叙事）。
- **公共学习**：组长带读 `README.md`"创新点二"小节，全组理解那条匹配准则。

### W11（11/30–12/6）：冲刺验证
- **电控组任务**：鲁棒性验证（J、B ±10% 摄动下四策略指标）；跑 `check_acceptance.py` 直到**全项 PASS**；必要时调 `g`/陷波器（组长主导）。
- **机械组任务**：整理全部机械交付物终版（模型文件入 `mechanical/cad/` 走 LFS + STEP 导出 + 截图）。
- **里程碑**：验收四项全 PASS，参数冻结。

### W12（12/7–12/13）：结题报告主体
- **全组任务**：写报告初稿。机械章：建模、参数、选型、协同分析；电控章：策略、推导（引用 `control_scheme.md`）、结果、创新点。
- **电控组任务**：整理全部图表（转速曲线、误差对比、DOB 收敛、刚度扫描图）。

### W13（12/14–12/20）：收尾与答辩
- **全组任务**：报告互审（机械审电控章、电控审机械章）→ 定稿；答辩 PPT + 每人预演 3 分钟。
- **仓库收尾**：确认 main 分支干净、文档齐全、tag 一个 `v1.0-final`。
- **里程碑**：结题材料全部提交。

## 四、每周节奏约定

1. **每天**：开工 Pull，收工 Commit+Push；`weekly_tasks.md` 每天上午 7 点前更新（组长）。
2. **每周日晚**：组长过一遍本文档，微调下一周（后移/砍深度，不砍交付物）。
3. **周会**：每周固定 30 分钟（建议周日晚），机械讲进度、电控讲进度、组长对齐接口。
4. **卡住就问**：Git 冲突、公式看不懂、软件报错——截图发群里，别自己憋两天。
