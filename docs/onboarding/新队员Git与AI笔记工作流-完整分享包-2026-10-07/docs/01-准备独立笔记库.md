# 1. 准备独立笔记库

## 先决定放在哪里

建议创建专用目录，例如：

```text
D:\知识管理\
├── AI项目知识库\       ← 本工作流的 Obsidian 库和 Git 仓库
└── 其他资料\

D:\项目\研发项目\     ← 原来的项目，彼此独立
```

不要把笔记库放进已有项目的 Git 仓库。否则新增笔记和 Obsidian 配置会出现在原项目的 Git 状态中，可能被一起提交。本次项目就因此进行了迁移。

**不只检查库自己有没有 `.git`，还要检查父目录是否属于已有仓库。**已安装 Git 时，在候选库目录运行 `git rev-parse --show-toplevel`：

- 返回另一个项目的路径：当前文件夹仍在那个项目内，换一个位置。
- 提示不是 Git 仓库：首次建库时正常。
- 返回库自身：它已经是独立仓库，不要重新初始化。

## 在 Obsidian 中打开

1. 创建文件夹。
2. 打开 Obsidian 的仓库管理，选择“打开文件夹作为仓库”。
3. 选择这个文件夹；软件会生成 `.obsidian` 配置目录。
4. 确认左下角显示的是新库名称。

安装脚本要求先打开过库，因为它通过 `.obsidian` 判断路径是否有效。仅新建文件夹还不够。

## 默认目录结构

```text
AI项目知识库/
├── .obsidian/                 本机界面和插件设置，默认不上传
├── .git/                      关联 GitHub 后生成
├── .gitignore
└── AI 项目笔记/
    ├── 索引.md
    ├── 2026/
    │   └── 日期-项目名称.md
    └── _attachments/
        └── 笔记名称/成果图片.png
```

年目录、笔记、附件和索引按需要生成，不要求提前全部创建。图片使用库内相对路径，便于换电脑使用。

## 如果已经把笔记放进了原项目

先检查 `git status --short` 和 `git ls-files -- 'AI 项目笔记'`。

- **未跟踪的笔记：**复制到独立库，核对文件数与内容，再移除原笔记目录。
- **已提交的笔记：**迁移后，原项目会显示删除；需要按团队流程提交迁移，不能当成“恢复干净”而丢弃其他改动。
- **其他 Obsidian 设置：**不要因为它们也显示未跟踪就一起删除，先确认是否属于你需要保留的原库设置。

迁移后更新**已安装技能**的 `settings.json`，确认 `vault_path` 指向新库。只修改下载包里的副本，不会改变当前技能的保存位置。

Obsidian 库默认保存在本地。云端同步是另外配置的步骤：[官方同步说明](https://help.obsidian.md/sync-notes)。
