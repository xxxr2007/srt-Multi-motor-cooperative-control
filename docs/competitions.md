# 跨组可打的比赛（机械组 / 电控组 / 联合）

> 本组不只是一个 SRT——机械组和电控组可以**各自单飞打本赛道比赛**，也可以**合队打跨赛道综合赛**。
> 本文件只做「方向+要做的事+与 SRT 的共同点」速查，保持简洁。详细赛制以当年官方通知为准。

## 0、本科生优先级速查（先打哪个）

> 排序原则：**本科友好度**（周期短、门槛低、不需大量实物投入）+ **与 SRT 同源度**（底子能直接复用）。

| 优先级 | 比赛 | 本科友好度 | 为什么先打这个 |
|---|---|---|---|
| 🥇 第一 | 中国大学生机械工程创新创意大赛（智能装备 / 数字孪生赛项） | ⭐⭐⭐ | 双惯量弹性系统 + 柔性联轴器 + 机电协同正是赛题题眼，SRT 仿真成果直接当作品 |
| 🥇 第一 | 「互联网+」/ 挑战杯 | ⭐⭐⭐ | 拿 SRT 当项目本体，`innovation.md` 三件套 + `acceptance_metrics.md` 验收口径改个封面就是申报书 |
| 🥇 第一 | 「西门子」杯（运动控制赛项） | ⭐⭐⭐ | 多轴同步、电子虚拟主轴与 SRT 同源，四策略可直接组态验证 |
| 🥈 第二 | 全国大学生电子设计竞赛（TI 杯，测控/电机题） | ⭐⭐ | 四策略上板跑，需买开发板但周期短 |
| 🥈 第二 | 全国大学生智能汽车竞赛 | ⭐⭐ | 转速环 / 同步误差闭环思路一致，需车模投入 |
| 🥈 第二 | 全国大学生机械创新设计大赛 | ⭐⭐ | 仅当当年主题对得上（如机构/样机类）才打，否则跳过 |
| 🥉 第三 | 慧鱼专项 / 工训赛 | ⭐ | 当「实物验证台 / 练兵」而非冲奖主力 |
| 🥉 第三 | 机器人大赛 / RoboMaster | ⭐ | 投入大、周期长，SRT 成熟后再考虑 |

**节奏建议**：W1–W13 先把 SRT 主体跑通（四策略对比 + 双惯量对象 + 创新点三件套）；**W13 之后**拿现成成果去打 🥇 三项和 🥈 电赛，最省力且最出彩。

## 四、共同点小结（为什么一套底子能打多赛）

1. **对象同源**：双惯量弹性系统 + 柔性联轴器，是「智能装备 / 机器人 / 智能制造」共同的核心机构。
2. **算法同源**：主从 / 交叉耦合 / 偏差耦合 / DCC+DOB 四策略，换平台（MATLAB→MCU→PLC）都能用。
3. **流程同源**：文献调研→建模→仿真→实物→数据留档→迭代，SRT 跑通的方法论直接套比赛。
4. **文档同源**：`innovation.md` 创新点、`acceptance_metrics.md` 验收口径、`weekly_tasks.md` 分工，改个封面就是申报书/说明书。

> 一句话：**SRT 是练兵场，比赛是考场；练兵时按比赛标准做，比赛时直接拎包上阵。**
