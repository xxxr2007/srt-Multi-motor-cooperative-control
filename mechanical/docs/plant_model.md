## 1. 命名与单位约定（先看这条，避免返工）

- 一律用 **SI 单位**：转动惯量 `kg·m²`、黏性摩擦 `N·m·s/rad`、转矩 `N·m`、转速 `rad/s`。
- CATIA 默认长度单位是 `mm`。测量前先把单位切到 **MGS 制**（工具 → 选项 → 参数与测量 → 单位：米/千克/秒），再用「测量惯量 Measure Inertia」功能，否则数值会差好几个数量级。
- 4 台电机同型号，参数带 ±10% 摄动：本表填**名义值（或 1 号机实测值）**，摄动范围填在第 4 节。

## 2. 电机本体与传动链参数

| 参数 | 符号 | 单位 | 物理含义 | 获取方式 | 当前占位值 | 机械组填写 |
|---|---|---|---|---|---|---|
| 转动惯量（含折算负载） | `J` | kg·m² | 转子 + 折算到电机轴的负载惯量 | CATIA「测量惯量 Measure Inertia」 | 0.010 |  |
| 黏性摩擦系数 | `B` | N·m·s/rad | 轴承 + 润滑的黏性阻尼 | **手册/经验值/实验辨识**（CATIA 给不出） | 0.0012 |  |
| 减速比 | `i` | — | 电机轴到负载轴的传动比 | 机构设计 | 1（直连） |  |
| 传动效率 | `η` | — | 减速器/皮带效率 | 手册 | 1.0 |  |
| 电机 + 负载质量 | `m` | kg | 转动部分总质量（供强度/选型参考） | CATIA「测量惯量 Measure Inertia」 | — |  |
| 峰值转矩 | `Tmax` | N·m | 电机/变频器能力上限 | 选型手册 | 5.0 |  |
| 额定转速 | `ω*` | rad/s | 工况目标转速 | 工况定义 | 120（≈1146 r/min） |  |

**折算公式**（若中间有减速器，把负载侧惯量折到电机轴）：

```
J_total = J_motor + J_load / i²          ← 惯量折算要乘 1/i²，不是 1/i
T_L(折算到电机轴) = T_load / (i · η)      ← 转矩折算要除 i·η
```

> 易错点：CATIA 测量惯量给的 J 默认是**绕零件自身轴**的（可在测量对话框里自选轴系统）。若把"电机 + 联轴器 + 负载"装配体一起算，
> 要确认软件给的是绕**电机轴**（装配体坐标系）的惯量，不能直接把各零件自身惯量相加。

## 3. 弹性传动链参数（方案 A 核心，机械组重点交付）

> 目的：把"刚性直连"升级为"电机—弹性轴—负载"的**双惯量模型**，让被控对象更接近真实机械。
> 这一节是机械组最能出彩的地方——**扭转刚度 `Ks` 直接决定控制系统需要多宽的带宽**。

| 参数 | 符号 | 单位 | 物理含义 | 获取方式 | 当前占位值 | 机械组填写 |
|---|---|---|---|---|---|---|
| 电机侧惯量 | `J₁` | kg·m² | 电机转子 + 主动轴 | CATIA「测量惯量 Measure Inertia」 | 0.010 |  |
| 负载侧惯量 | `J₂` | kg·m² | 负载 + 从动轴 | CATIA「测量惯量 Measure Inertia」 | 0.010 |  |
| 联轴器扭转刚度 | `Ks` | N·m/rad | 弹性轴的抗扭刚度 | **联轴器手册**（选型参数） | 待定 |  |
| 联轴器阻尼 | `Ds` | N·m·s/rad | 弹性轴结构阻尼 | 手册/经验（可取临界阻尼的 1%~5%） | 待定 |  |

**谐振频率（机械组请算出来交给电控组）**：

```
ω_n = √( Ks · (1/J₁ + 1/J₂) )
```

算例：`Ks = 100 N·m/rad`、`J₁ = J₂ = 0.01 kg·m²` → `ω_n = √(100 × 200) ≈ 141 rad/s`。

> **这就是两组的耦合点**：电控组的观测器带宽 `g` 必须覆盖 `ω_n` 的 2~5 倍才能压住谐振。
> 若机械给的 `Ks` 偏大（`ω_n` 超出 `g`），要么换更软的联轴器、要么提高控制带宽——
> 这个"谁让一步"的讨论，就是报告里"机电协同设计"的核心内容。

**联轴器选型要求**：给 **2~3 个方案**（如刚性 / 弹性柱销 / 膜片联轴器），
每个方案写清 `Ks` 数值与选型理由，供电控组做 `Ks × g` 扫描对比。

## 6. 交接流程（机械组 → 电控组）

```
CATIA 建模（先简化：只留电机转子 + 联轴器 + 主要负载）
   ↓ 导出 MKS 单位的质量属性
填本表（第 2、3 节，说明物理含义与来源）
   ↓ 同时把数值写进 data/mechanical/mech_params.json（版本号 +1）
提交：git add data/mechanical/ → commit → push，群里通知
   ↓ 电控组执行
python electrical/c/merge_params.py      ← 合并 + 校验（含 ω_n 与带宽匹配检查）
   ↓
重新编译 C 内核 / 重跑 params_setup → 仿真参数全部更新
```

**节奏要求**：先给出**数量和量级**（如"J 约 10⁻² kg·m² 量级、B 约 10⁻³ 量级"），
让仿真框架先跑起来；精确值后续迭代替换。不要等全部算准了才交付。
