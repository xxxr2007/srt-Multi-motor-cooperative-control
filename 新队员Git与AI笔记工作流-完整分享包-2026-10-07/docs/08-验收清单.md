# 8. 队友使用前的验收清单

按实际结果勾选，不要仅凭“安装成功”勾选同步成功。

## 本地准备

- [ ] 笔记库位于原项目仓库之外。
- [ ] Obsidian 能打开独立库，左下角名称正确。
- [ ] 安装后的 settings.json 指向自己的库，分享版空路径未残留。
- [ ] 新 Codex 聊天能说明项目收尾规则。
- [ ] 做过一次“预览 → 确认保存”，笔记与索引能打开，流程图可显示。

## 云端接入

- [ ] 已创建或获授权访问目标私人 GitHub 仓库。
- [ ] origin 地址正确，当前分支有上游分支。
- [ ] 手动首次推送成功，GitHub 能看到初始笔记。
- [ ] .obsidian/ 按团队约定忽略，每台电脑单独配置插件。

## 自动化验收

- [ ] Git 插件安装、启用，能找到 Git。
- [ ] Automatic 的同步间隔为 5；独立提交/推送间隔关闭。
- [ ] Sync 页的推送、同步时拉取、启动时拉取已开启。
- [ ] only staged files 与自动自定义提交消息提示已关闭。
- [ ] 新建唯一标记测试笔记，记录创建时间。
- [ ] 保持 Obsidian 运行，不手动提交或推送。
- [ ] 测试标记进入本地提交。
- [ ] 实时远程提交中的测试文件含相同标记。

## 日常使用

- [ ] 队友知道 Obsidian 关闭时插件不会继续后台上传。
- [ ] 队友知道网络错误意味着“无法验证”，不是“云端一定没有”。
- [ ] 队友知道冲突应检查并整合，不默认强制覆盖。
- [ ] 换库时更新已安装技能设置，而不是只修改分享包。
