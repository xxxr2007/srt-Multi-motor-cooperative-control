# 新队员 Git 与 AI 笔记工作流 · 完整分享包

版本：2026-10-07。Windows 图形操作入门；AI 工具自选。

**先读 [新队员上手指南](新队员上手指南.md)。**这是本包当前主指南，包含官方下载、统一用户名与邮箱、SourceGit 操作、Git-Test 自我介绍分支/PR/合并练习、个人笔记仓库、不同 AI 的配置路线和五分钟同步验收。

## 使用顺序

1. 全部解压，使用 VS Code 或其他 Markdown 阅读器打开上手指南；也可用 Obsidian 阅读。不要只从 ZIP 中打开单个文件。
2. 跟随指南安装软件，并在练习仓库完成练习。
3. 建立自己的独立 Obsidian 库，配置笔记同步。
4. 按指南第 7 节选择 Codex / 其他本地 AI / 网页聊天路线，测试预览、保存和自动上传。

## 包内内容

- `新队员上手指南.md`：新队员按这一份操作，无需另找附件。
- `obsidian-project-notes/`：技能说明、笔记模板、初始个人配置。
- `global-instructions.md`：Codex 项目收尾规则。
- `install.ps1`：原 v2 Windows Codex 安装器，其他 AI 不使用。该脚本写入 .codex/skills，先按主指南确认当前 Codex 是否加载此目录；不加载时让助手按当前支持的目录安装。升级需保留个人配置。
- `docs/`：v2 原始技术参考、排错和项目复盘。它们包含命令行示例，新人日常操作以当前主指南的 SourceGit 步骤为准。
- `scripts/`：原 v2 同步测试辅助工具，可选；新人可以直接按主指南做图形化/手动测试。

安装器仅安装本地 Codex 技能和规则，不安装 Git/Obsidian 插件，不创建 GitHub 仓库，不上传笔记。初始 settings.json 的库路径为空，必须配置为使用者自己的路径。其他 AI 的通用提示词已直接放在主指南中，不需要运行 Codex 脚本。

可直接转发这个完整 ZIP。包内没有原作者的个人库配置、私人笔记、聊天记录、备份、账号凭据或软件安装包。Git-Test 练习仓库地址按团队要求保留，访问仍需负责人邀请。
